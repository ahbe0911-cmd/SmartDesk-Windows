# SmartDesk Windows — میزکار هوشمند

یک مرورگر و میزکار فارسی برای Windows 10 و Windows 11 که سایت‌های کاری را با موتور امن **Microsoft Edge WebView2** داخل خود برنامه اجرا می‌کند.

## امکانات نسخه ۱.۰

- رابط فارسی و کاملاً راست‌چین با پوسته روشن، تیره و هماهنگ با ویندوز
- مرورگر داخلی مبتنی بر Edge/Chromium
- زبانه‌های متعدد و پشتیبانی از پنجره‌های بازشونده سایت‌ها
- عقب، جلو، تازه‌سازی، صفحه خانه و نوار نشانی هوشمند
- بازکردن اختیاری صفحه در مرورگر پیش‌فرض ویندوز
- میانبرهای قابل افزودن، ویرایش، حذف و جست‌وجو
- تاریخ شمسی و ساعت ۲۴ ساعته
- نگهداری ورود به سایت‌ها، کوکی‌ها و داده مرورگر در پوشه اختصاصی کاربر
- بازیابی زبانه‌های جلسه قبل
- خروجی و بازیابی فایل پشتیبان تنظیمات و میانبرها
- نصب برای حساب کاربری فعلی، بدون نیاز به دسترسی Administrator
- گزارش خطای محلی بدون ارسال اطلاعات به سرویس خارجی

## امنیت

- فقط نشانی‌های `http` و `https` داخل مرورگر اجرا می‌شوند.
- پیوندهای `mailto` و `tel` به برنامه استاندارد ویندوز سپرده می‌شوند.
- بررسی گواهی SSL غیرفعال نشده است.
- برنامه هیچ رمز، توکن یا کلید API را در مخزن نگهداری نمی‌کند.
- ابزار توسعه مرورگر در نسخه انتشار غیرفعال است.

## پیش‌نیاز اجرا

- Windows 10 نسخه 1809 یا جدیدتر، یا Windows 11
- معماری 64 بیتی
- WebView2 Runtime؛ نصب‌کننده رسمی آن همراه Setup اجرا می‌شود.

فایل خروجی به‌صورت Self-contained ساخته می‌شود و کاربر لازم نیست .NET را جداگانه نصب کند.

## دریافت فایل نصب

به بخش **Actions** مخزن بروید، آخرین اجرای سبز `Build SmartDesk Windows` را باز کنید و Artifact با نام زیر را بگیرید:

```text
SmartDesk-Setup-Windows-x64
```

نسخه بدون نصب نیز با نام `SmartDesk-Portable-Windows-x64` ساخته می‌شود.

## ساخت محلی

```powershell
dotnet restore src/SmartDesk/SmartDesk.csproj
dotnet publish src/SmartDesk/SmartDesk.csproj -c Release -r win-x64 --self-contained true
```

فناوری‌های اصلی: .NET 10 LTS، WPF و Microsoft Edge WebView2.
